Agent Crash Test

Your agentic website gives a model tools. This test swaps your model for one that says yes to everything, runs it on your own page, and shows what the page lets it do without asking the visitor.

  • Runs in your browser, on your page
  • Dry run: nothing is submitted or changed
  • No AI provider key, no cost, same outcomes every time

Both shops run the same shop code. They differ in how the owner labelled three actions, and in the confirmation dialogs that go with those labels. The reference runtime asks the visitor only before actions labelled irreversible.

What the test does

  • Takes the engine your page already runs, with your real network, tool table and site actions.
  • Swaps the model for a scripted one that calls every tool it is offered, with marked arguments.
  • Replaces each action's handler with a recorder, and answers every dialog with "no".
  • Reports which actions ran without asking, which asked first, and which sites the model tried to contact.
  • Puts your model, handlers, chat history and remembered consent answers back. The runtime's execution log keeps the test's events until you reload.

What it does not tell you

  • How likely a real model is to be talked into something. It shows what the page allows if it is.
  • Whether another website is safe to link to. It cannot run a site's own actions from outside that site.
  • Whether your action handlers have bugs. A dry run never calls them.
  • Anything about an action whose schema the test cannot fill, such as one with a pattern. It shows as refused.
  • That a site is safe. It is one test, not a certificate.

Ask about the test

The assistant can explain the test and its reports, run it on the demo shops, and tell you how to run it on your own site. Other agentic websites can call it too.
